# Address autocomplete attribution

`powered-by-google-on-white.png` is Google's unmodified legacy Places attribution
asset, downloaded from:
https://maps.gstatic.com/mapfiles/api-3/images/powered-by-google-on-white3.png

It replaces a hand-built wordmark in the existing Places implementation. Google
permits existing implementations to continue the previous Google attribution:
https://developers.google.com/maps/documentation/places/web-service/policies

Keep its colours, aspect ratio and visibility unchanged. Google owns the mark.
