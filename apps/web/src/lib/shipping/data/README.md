# Nigeria recovery boundary

`nigeria-adm0-boundary.json` contains the complete Polygon geometry extracted
from geoBoundaries **NGA-ADM0-39225661**, representing Nigeria in 2022.
Source: **GRID3**, distributed by geoBoundaries under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

- [Dataset metadata](https://www.geoboundaries.org/api/current/gbOpen/NGA/ADM0/)
- [Immutable source at revision 9469f09](https://github.com/wmgeolab/geoBoundaries/blob/9469f09/releaseData/gbOpen/NGA/ADM0/geoBoundaries-NGA-ADM0.geojson)
- Original GeoJSON SHA-256: `cb2407fde9f81c67a3637fbc13bd1c7bcfe20c469eba77148b3e4895ee33acaa`

Only the FeatureCollection wrapper and properties were removed. Coordinates,
precision and ring order are unchanged: one ring, 7,205 vertices. No inset,
buffer or simplification was applied. This static national scope check does
not establish carrier serviceability or customer acceptance of a destination.
Recovery still requires explicit destination confirmation and a matching paid fee.
