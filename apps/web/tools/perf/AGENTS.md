# Storefront measurement tools

For storefront rendering/performance work, read
`docs/perf/storefront-visual-regression.md` from the repository root.
Use the route matrix here for mobile/desktop coverage. A passing score with
broken images, missing video, wrong routing or unreviewed flashes is not proof
of a successful visual fix. Preserve production security when adapting a local
test harness. Do not claim the sitespeed.io batch ran unless its artifacts exist.
